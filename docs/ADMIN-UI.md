# تحویل پنل مدیریت LaunchoX

شاخه: `ui/admin`؛ مبنا: `82fb6f3` از `main`.

## کامپوننت‌ها

| مسیر در `src/components/admin/` | مسئولیت |
| --- | --- |
| `AdminForm.tsx` | بخش‌بندی فرم، برچسب و خطای فیلد، انتخاب‌گر، وضعیت، پیام ذخیره و پیش‌نمایش تصویر |
| `use-admin-form-action.ts` | ذخیره‌های پس از ساخت، همان رکورد را ویرایش می‌کنند؛ حتی بعد از خطای اعتبارسنجی |
| `ProductForm.tsx` | محصول، دسته و برند، قیمت و موجودی، ترتیب تصاویر، مشخصات و انتشار |
| `CategoryForm.tsx` | دسته و والد مجاز، توضیح، تصویر، ترتیب و وضعیت |
| `BrandForm.tsx` | نام و نامک، کشور و سایت، لوگو، توضیح، ترتیب، فعال و ویژه |
| `BrandRowActions.tsx` | ویرایش و حذف با تأیید؛ نمایش خطای برند دارای محصول |
| `AdminNavigation.tsx` | مسیر فعال، ناوبری دسکتاپ، dialog موبایل، Escape و بازگرداندن فوکوس |
| `OrderStatusForm.tsx` | فقط انتقال وضعیت مجاز؛ تأیید لغو و پیام نتیجه |
| `UserActiveForm.tsx` | کلید وضعیت حساب؛ حفظ محدودیت غیرفعال‌سازی خود ادمین |
| `Admin.module.css` | پالت روشن مصوب، فرم و جدول خوانا، RTL و واکنش‌گرایی فقط در محدوده ادمین |

## صفحات

- داشبورد: آمار واقعی، سفارش‌های آخر، موجودی کم و پیوند به محصول و سفارش.
- محصولات و دسته‌بندی‌ها: فهرست، ایجاد و ویرایش با سرویس‌های فعلی.
- برندها: `/admin/brands`، `/admin/brands/new`، `/admin/brands/[id]/edit`؛ جستجو، فیلتر فعال/غیرفعال/ویژه، حالت خالی و loading.
- سفارش‌ها: فیلتر وضعیت، جدول و نشان پرداخت، جزئیات اقلام/مشتری/آدرس/پرداخت/تاریخچه.
- کاربران: اطلاعات حساب، نقش و وضعیت، اعلان نتیجه تغییر.

## اتصال داده و محدوده

- مدل Brand از قبل موجود بود. هیچ مدل یا DTO مشترکی تغییر نکرد.
- اکشن محصول شناسه برند را اعتبارسنجی می‌کند؛ سرویس وجود برند را قبل از ذخیره بررسی می‌کند. انتخاب «بدون برند» ارتباط را پاک می‌کند.
- مشخصه متنی قدیمی برند برای سازگاری با فیلترهای فروشگاه نگه داشته شده است.
- `src/app/layout.tsx`، `src/app/globals.css`، `src/components/ui/*` و `src/types/*` ویرایش نشده‌اند. پالت مصوب در محدوده ادمین تعریف شده تا هماهنگی بعدی توکن‌های مشترک مستقل بماند.
- تصویر و لوگو از URL یا مسیر موجود خوانده می‌شوند؛ آپلود فایل اضافه نشده است.
- صفحات داده Server Component هستند؛ فقط فرم‌ها و منوی تعاملی در کلاینت اجرا می‌شوند. وابستگی جدیدی اضافه نشده است.

## بررسی

- TypeScript، ESLint، تست‌های Vitest و build نهایی بررسی شدند.
- ۳۷۴ تست موفق؛ تست جدید اتصال و تغییر برند، پاک‌کردن ارتباط و جلوگیری از حذف برند دارای محصول را پوشش می‌دهد.
- ۹ صفحه در چهار عرض ۳۶۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ بررسی شدند؛ اسکرول جدول در ظرف خودش است.
- مرورگر: ساخت و ویرایش برند، اعتبارسنجی و حفظ داده پس از خطا، ویرایش همان رکورد پس از ساخت، اعتبارسنجی قیمت محصول، ترتیب تصاویر، ارتباط برند و محدودیت حذف، ساخت دسته، تغییر سفارش از آماده‌سازی به ارسال‌شده، فعال/غیرفعال‌سازی مشتری و ممنوعیت غیرفعال‌سازی خود ادمین.
- داده تصاویر آزمایشی و متعلق به دیتابیس مجزای `launchox_admin_qa` است؛ داده پروژه اصلی تغییر نکرد.
