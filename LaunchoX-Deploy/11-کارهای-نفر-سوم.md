## ۴. تنظیمات و رفتارشان

| متغیر | مقدار فعلی | اگر عوض شد چه لازم است |
|---|---|---|
| `MONGODB_URI` | ناقص — باید اصلاح شود | ری‌استارت سرویس |
| `AUTH_SECRET` | ۶۴ کاراکتر | همهٔ کاربران خارج می‌شوند |
| `AUTH_URL` | `https://luanchox-2m1-luanchox.runflare.cloud` | **build مجدد** |
| `NEXT_PUBLIC_SITE_URL` | همان آدرس موقت | **build مجدد** |
| `NEXT_PUBLIC_SITE_NAME` | `لانچو ایکس` | build مجدد |
| `PAYMENT_PROVIDER` | `fake` | در این پروژه فقط fake پیاده شده |
| `SHIPPING_FLAT_FEE` | `50000` تومان | ری‌استارت |
| `FREE_SHIPPING_THRESHOLD` | `1000000` تومان | ری‌استارت |
| `AUTH_TRUST_PROXY_HEADERS` | خالی (false) | تغییر در شمارش محدودیت تلاش |
| `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` | مقدار نمونه / رمز تنظیم‌شده | فقط هنگام اجرای seed لازم است |

**نکتهٔ کلیدی:** هر متغیری که با `NEXT_PUBLIC_` شروع شود در زمان **build** پخته می‌شود. تغییرش بدون build مجدد، هیچ اثری ندارد.

## ۸. کارهای باقی‌مانده (به ترتیب)

1. ☐ اصلاح `MONGODB_URI` (نیاز به Host و Port از پنل)
2. ☐ اتصال ریپوی گیت‌هاب و اولین build
3. ☐ گذاشتن متغیرها در پنل
4. ☐ اجرای `seed` و ساخت حساب ادمین
5. ☐ تست کامل توسط نفر دوم (`10-کارهای-نفر-دوم.md` + `14-گزارش-تست.md`)
6. ☐ تغییر ایمیل ادمین از مقدار نمونه
7. ☐ خرید و اتصال دامنه (`12-مهاجرت-به-دامنه.md`)
8. ☐ بکاپ اول و تمرین بازیابی
9. ☐ حذف آدرس موقت از مستندات و پیام‌ها
