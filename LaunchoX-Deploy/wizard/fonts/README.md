# فونت وزیرمتن

فایل‌های این پوشه از پروژهٔ [Vazirmatn](https://github.com/rastikerdar/vazirmatn) هستند و تحت
مجوز SIL Open Font License 1.1 منتشر می‌شوند. متن کامل مجوز در فایل `OFL.txt` کنار همین فایل است.

استفاده: صفحهٔ ویزارد (`wizard/ui.html`) این سه فایل را از مسیر `/fonts/` سرو می‌کند تا متن فارسی
بدون وابستگی به اینترنت و بدون فونت نصب‌شده روی سیستم، درست نمایش داده شود.
