## ۶. آپلود تصویر — با فایل‌های آماده

در پوشهٔ `تست-آپلود` چهار فایل آماده گذاشته شده است. همین‌ها را استفاده کن تا نتیجه قابل مقایسه باشد:

| فایل | حجم | انتظار | نتیجهٔ واقعی |
|---|---|---|---|
| `1-کوچک-معتبر.png` | ۳ کیلوبایت | قبول شود | |
| `2-نزدیک-سقف.png` | ۴.۱ مگابایت | قبول شود | |
| `3-بزرگتر-از-سقف.png` | ۶.۴ مگابایت | رد شود با پیام روشن | |
| `4-جعلی.png` | ۷۷ بایت (متن با پسوند عکس) | رد شود | |
| `5-معتبر.jpg` | ۲۰ کیلوبایت | قبول شود | |

بعد از هر آپلود موفق، بررسی کن که عکس در صفحهٔ محصول **دیده** شود، نه فقط ذخیره.

اگر آپلود موفق بود ولی ذخیرهٔ محصول شکست خورد: این را جدا ثبت کن. نشانهٔ مشکل دیتابیس است، نه فرم، و باید به نفر اول گزارش شود.
