# انتشار در گیت‌هاب

این پوشه مجموعهٔ ابزار و مستندات استقرار است، نه کد فروشگاه. می‌شود در گیت‌هاب منتشرش کرد، به شرط یک نکته.

---

## ⚠️ نکتهٔ اصلی

فایل `02-env.production.txt` **رمز دیتابیس، کلید امنیتی نشست و رمز ادمین** را دارد. هرگز نباید در گیت برود — نه در ریپوی عمومی، نه خصوصی.

برای همین یک `.gitignore` در همین پوشه گذاشته شد که این فایل‌ها را نادیده می‌گیرد:

| فایل | چرا |
|---|---|
| `02-env.production.txt` | رمز دیتابیس و سکرت‌ها |
| `last-result.txt` | خروجی ابزارها، ممکن است آدرس دیتابیس داشته باشد |
| `wizard/state.json` | وضعیت محلی ویزارد |

اگر روزی به‌زور `git add -f` بزنی یا `.gitignore` را پاک کنی، رمزها می‌روند بالا. در آن صورت:
۱. رمز دیتابیس را عوض کن، ۲. `AUTH_SECRET` جدید بساز، ۳. رمز ادمین را عوض کن. حذف فایل از کامیت کافی نیست؛ تاریخچهٔ گیت نگهش می‌دارد.

## چه چیزی منتشر می‌شود

**بی‌خطر:**
- مستندات: `00` تا `14` (فایل‌های md)

**ممنوع:** `02-env.production.txt`

---

## گیت‌هاب: ریپوی جدا بساز

این پوشه را داخل ریپوی خود فروشگاه نگذار. دو دلیل:

- ریپوی `LaunchoX` کد برنامه است؛ این پوشه ابزار و مستندات عملیات است و تاریخچهٔ تغییراتشان یکی نیست.
- اگر `.gitignore` فروشگاه را تغییر دهی، ممکن است تصادفاً این فایل‌ها هم وارد شوند.

یک ریپوی جدا بساز، مثلاً `LaunchoX-deploy`.

---

## دستورها

پوشه روی دسکتاپ است و ریپوی گیت محلی هم در آن ساخته شده. فقط باید مخزن راه دور را وصل کنی:

```powershell
cd "$env:USERPROFILE\Desktop\LaunchoX-Deploy"

# یک ریپوی خالی در گیت‌هاب بساز (بدون README و .gitignore)، بعد:
git remote add origin https://github.com/USERNAME/LaunchoX-deploy.git
git branch -M main
git push -u origin main
```

اگر اولین بار است که با گیت‌هاب از این سیستم push می‌کنی، احتمالاً یک صفحهٔ ورود یا توکن می‌خواهد؛ دنبالش را بگیر.
